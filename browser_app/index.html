This app processes selected CSV, Excel, and selectable-text PDF files locally in your browser. It does not send statement contents to a server. Its spreadsheet and PDF readers are included with this website; it has no account, database, analytics, or external OCR connection.

When hosted online, the website host still receives ordinary page requests, such as your IP address. This app does not include statement contents in those requests. Browser extensions or device software with access to page content may still be able to read what is displayed.
